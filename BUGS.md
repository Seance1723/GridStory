## Severity

- **Critical:** data exposure/loss, authorization bypass, remote code execution, or unusable production system.
- **High:** core workflow failure with no safe workaround.
- **Medium:** incorrect behavior with a workaround or limited scope.
- **Low:** cosmetic, usability, documentation, or non-blocking quality issue.
